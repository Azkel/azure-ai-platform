# Contributing

Thanks for your interest in Azure AI Platform Labs.

---

## Before you contribute

1. Read [`README.md`](./README.md) for repo scope and technical direction.
2. Open an issue for non-trivial changes before starting large work.
3. Do not include secrets, credentials, or organization-specific data.

---

## Pull requests

- One lab or one concern per PR when possible
- Include or update `README.md` for anything user-facing
- Terraform: `terraform fmt` and validate before opening
- .NET: build and test before opening
